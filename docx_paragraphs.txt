Mô tả bài toán
Ký túc xá mở dịch vụ giao đồ tận phòng tên KTXGo. Sinh viên đặt đồ ăn, nước, văn phòng phẩm trên điện thoại; shipper nội khu mang đến đúng tầng / phòng — có giỏ nhiều món, có ước tính phí ship theo khoảng cách GPS, không thanh toán online trong giờ thi.
Bạn dựng một app React Native chạy trên máy ảo với: Auth Stack (Đăng nhập) → Main Tabs (Cửa hàng · Giỏ · Tôi); trong tab Cửa hàng có Stack Home (lưới 2 cột) → Chi tiết; giỏ Zustand + Persist; list món React Query + Axios; màn Tôi xin quyền Location + Haptic. Ba câu là cùng một project.
Phạm vi: Chương 4 (Flexbox, FlashList 2 cột, Debounce, Pull-to-refresh, SafeArea) · Chương 5 (React Navigation V7 — Stack + Tabs + Auth) · Chương 6 (Zustand persist, React Query, Axios) · Chương 7 (Permissions Location, Haptic, Linking.openSettings).

Định danh — chỉ 2 ô: MSSV và họ tên
Mở src/constants/student.ts, điền đúng bạn (họ tên IN HOA). Cấm để nguyên mẫu nếu không phải bạn. Cấm viết cứng debounce / staleTime / giá / phí ship.
export const STUDENT = {
  mssv: '22612345',
  hoTen: 'NGUYEN VAN A',
} as const;
const soCuoi = Number(STUDENT.mssv.slice(-1));
export const LAST_DIGIT = soCuoi;
export const STUDENT_SEED = parseInt(STUDENT.mssv.slice(-3), 10) || 1;
export const DEBOUNCE_MS = 300 + (STUDENT_SEED % 5) * 100;
export const STALE_TIME_MS = 10_000 + (STUDENT_SEED % 20) * 1000;
export const PRICE_MULTIPLIER = 15000 + (STUDENT_SEED % 40) * 500;
export const BASE_SHIP_FEE = 8000 + (STUDENT_SEED % 10) * 1000;
export const ROOM_LABEL = `P.${100 + (STUDENT_SEED % 400)}`;
export const BANNER_IMAGE_ID = 200 + (STUDENT_SEED % 150);
export const VARIANT = {
  watermarkAtTop: LAST_DIGIT % 2 === 0,
  authField: LAST_DIGIT % 2 === 0 ? 'email' : 'phone',
  tabOrder: LAST_DIGIT >= 5 ? 'cartFirst' : 'shopFirst',
  hapticOnAdd: LAST_DIGIT % 3 === 0 ? 'impact' : 'selection',
  shipFormula: LAST_DIGIT % 2 === 0 ? 'A' : 'B',
  detailPresentation: LAST_DIGIT >= 5 ? 'modal' : 'card',
} as const;
export function examStamp(): string {
  const raw = `TH2|${STUDENT.mssv}|${STUDENT.hoTen}`;
  let h = 5381;
  for (let i = 0; i < raw.length; i++) {
    h = Math.imul(h, 33) ^ raw.charCodeAt(i);
  }
  return String(Math.abs(h) % 1000000).padStart(6, '0');
}
Trên mọi màn chính, một dòng tên phải hiện:
TH2 · {mssv} · {hoTen} · #{examStamp()}
Ví dụ: TH2 · 22612345 · NGUYEN VAN A · #4F21A9
Các số lấy từ file trên, không gõ tay:
•  Debounce: useDebouncedValue(..., DEBOUNCE_MS)
•  React Query: staleTime: STALE_TIME_MS
•  Giá: Math.round(price * PRICE_MULTIPLIER) + toLocaleString('vi-VN') + ' đ'
•  Key list: ` ${STUDENT.mssv}-${item.id} 
•  Phòng giao: ROOM_LABEL — Persist key giỏ: ` ktxgo-cart-${mssv} 
package.json name: ktxgo-<mssv>. Dòng đầu App.tsx: // TH2 | MSSV | HO TEN | #STAMP.

Giao diện 1 — Đăng nhập (Auth)
Chưa có token Zustand → chỉ thấy Login. Ô nhập email hoặc phone đúng bảng số cuối. Nút Vào cửa hàng lưu token giả ktxgo-{mssv}-{stamp} rồi vào Main Tabs.
Hình 1. Login KTXGo — nền #EFF6FF, nút primary #1D4ED8.
Giao diện 2 — Tab Cửa hàng (FlashList lưới 2 cột)
Dựng giống màu và bố cục hình dưới. Watermark trên/dưới theo số cuối. Ô tìm dùng chuỗi đã debounce. Bấm + → thêm giỏ + Haptic; bấm card → Detail.
Hình 2. Home — FlashList numColumns={2}, badge giỏ, pull-to-refresh.
Đọc hình:
(0) STUDENT + examStamp(), không gõ cứng tên người khác.
(A) Header KTXGO + Giao tận {ROOM_LABEL}.
(B) Ô tìm controlled; filter theo bản debounce DEBOUNCE_MS.
(C) FlashList 2 cột; không bọc ScrollView dọc; key ghép mssv.
Ba cảnh mạng (thiếu một = sai Câu 2b):
Hình 3. Đang tải · Có dữ liệu lưới · Lỗi mạng (có MSSV + Thử lại).
Giao diện 3 — Chi tiết món (Stack)
route.params.id. Presentation card hoặc modal theo bảng. Nút Thêm vào giỏ → Zustand + Haptic + Alert có MSSV.
Hình 4. Detail — Stack push từ Home.
Giao diện 4 — Tab Giỏ + Tab Tôi
Giỏ: sửa SL, xoá, tổng tiền, ROOM_LABEL, phí ship (nếu đã có location). Persist AsyncStorage. Tôi: 3 nhánh quyền Location + Haversine + công thức A/B + openSettings khi blocked + Đăng xuất.
Hình 5. Tab Giỏ (trái) và Tab Tôi / Location (phải).
Dữ liệu món & mạng
Axios apiClient.ts (axios.create + interceptor gắn X-Student-Id: {mssv}). GET https://fakestoreapi.com/products?limit=12 qua useQuery. App.tsx: SafeAreaProvider → QueryClientProvider → NavigationContainer → RootNavigator.
