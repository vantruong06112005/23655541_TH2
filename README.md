# KTXGo - Thực hành 2

Ứng dụng giao đồ tận phòng ký túc xá, viết bằng React Native CLI + TypeScript.

## Chạy project

```sh
npm install
npm start
```

Mở terminal khác (đã bật emulator Android):

```sh
npm run android
```

## Công nghệ

- React Navigation V7 (Auth Stack, Main Tabs, Shop Stack)
- FlashList lưới 2 cột
- Zustand + persist (AsyncStorage)
- TanStack Query + Axios
- expo-location + expo-haptics
